CI/CD Pipeline

How Our Pipeline Works

🔍

1. Lint

Checks code style and formatting rules so the team writes consistent, clean code.

→
🧪

2. Test

Runs automated tests to catch bugs early before code reaches production.

→
📦

3. Build

Bundles and optimises all assets into a production-ready dist/ folder.

→
☁️

4. Deploy

Uploads the dist/ folder to an AWS S3 bucket and serves it as a website.

🌿 Branch Strategy

  • main — production deploys trigger here
  • develop — CI runs (lint + test) on every push
  • feature/* — CI runs on pull requests

🔐 Secrets Used

  • AWS_ACCESS_KEY_ID
  • AWS_SECRET_ACCESS_KEY
  • AWS_REGION
  • S3_BUCKET_NAME
